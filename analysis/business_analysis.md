# Business Analysis Notes

## Decision Framework
1. Rank branches by operating profit and margin.
2. Compare revenue productivity against fixed and variable costs.
3. Identify high-revenue/low-margin branches for root-cause review.
4. Identify sustained low-profit branches for turnaround or consolidation review.
5. Use scenario analysis before expansion or closure decisions.

## Core KPIs
- Revenue
- Gross Profit
- Operating Cost
- Operating Profit
- Operating Margin %
- Revenue per Sq Ft
- Sales per Employee
- Return on Branch Investment

## Management Questions
- Which branch should receive additional investment?
- Which branch needs a cost-reduction programme?
- Which branches should be monitored for consolidation?

## Recommendation Principle
Recommendations should be based on both absolute profit and profitability efficiency; high revenue alone is not sufficient evidence for expansion.
