# Branch Profitability & Network Optimization

Business Analyst case study focused on branch-level profitability, cost drivers, performance benchmarking, and network optimisation decisions.

## Business Objective

Determine which branches create economic value, identify the drivers behind underperformance, and prioritise operational or expansion decisions.

## Key Questions
- Which branches generate the highest revenue and operating profit?
- Which cost categories are putting pressure on margins?
- Which branches have strong sales but weak profitability?
- Where should management invest, improve, consolidate, or exit?
- What happens to network profit under alternative scenarios?

## Deliverables
- Synthetic branch and transaction dataset
- SQL business analysis
- Python/Pandas analysis
- KPI definitions
- Power BI dashboard specification
- Management recommendations

## Tech Stack
Excel | SQL/MySQL | Python/Pandas | Power BI | DAX

## Data Note
This is a synthetic portfolio case study created for business-analysis demonstration. Financial figures are illustrative and are not company data.
