# Power BI Dashboard Specification

## Executive Overview
KPI cards: Revenue, Operating Profit, Operating Margin, Branch Count, Average Profit per Branch.

## Visuals
1. Revenue vs Operating Profit by Branch
2. Operating Margin ranking
3. Cost mix by Branch
4. Monthly Revenue and Profit trend
5. Branch quadrant: Revenue vs Margin
6. Drill-through: Branch detail

## Filters
Month | Branch | Region

## Management Story
Use the quadrant to separate scale leaders, efficient branches, turnaround candidates, and possible consolidation candidates.
